# ショップ・アイテム改善案メモ

対象日: 2026-05-25
対象範囲: ショップ、アイテム購入、アイテム使用タイミング、追加アイテム案

## 現状まとめ

- ショップの商品は `src/data/shopItems.ts` に4種類あります。
  - ゲージボール: 次の捕獲でゲージ増加量アップ
  - げんきパン: 次の対戦で味方のHP +15
  - なかまよび: いまの仲間をもう一度呼び出す想定
  - レアベル: レアがいるステージで次にレアを出す
- 購入処理は `src/state/save.ts` の `buyShopItem()` が、所持数を増やす形です。
- 使用処理は `consumeShopItem()` に集約されています。
- 現状は「使うかどうかを選ぶ」よりも、該当画面に入った時点で自動的に使う設計です。
  - ゲージボール: 捕獲中、最初の正解時に自動消費
  - げんきパン: 対戦開始時に自動消費
  - レアベル: ステージ出発時、レアがいるステージなら自動消費
- ショップ画面は購入と交換が同じ Scene にあり、アイテム追加数が増えると表示領域がすぐ足りなくなります。

## 最優先で直したい点

### 1. なかまよびが未完成

`ResultScene` に `なかまよび` ボタンはありますが、クリック先の `startNakamaCallCapture()` が実装されていません。現状の型チェックでもここで止まります。

確認結果:

```text
src/game/scenes/ResultScene.ts(20,3): error TS6133: 'recordEncounterMonster' is declared but its value is never read.
src/game/scenes/ResultScene.ts(22,3): error TS6133: 'recordStagePlayEntryUsingItem' is declared but its value is never read.
src/game/scenes/ResultScene.ts(523,29): error TS2339: Property 'startNakamaCallCapture' does not exist on type 'ResultScene'.
```

想定される仕様:

- リザルト画面で `なかまよび` を押す
- ステージ制限に余裕がある場合だけ、`なかまよび` を1個消費
- 直前に捕まえたモンスターと同じ `monsterId` で捕獲画面へ入る
- 出発回数は通常と同じく1回分カウントする
- 失敗時は消費しない

このアイテムは「購入した意味が分かりやすい」ので、まず完成させる価値が高いです。

### 2. 高価なアイテムが自動消費される

特に `レアベル` は1000コインと高価なのに、対象ステージで出発すると自動で使われます。プレイヤーが「今使いたい」と選ぶ体験にした方が、納得感があります。

変更方針:

- 捕獲系アイテムはステージ導入画面で選ぶ
- 対戦系アイテムは対戦相手選択、またはパーティ確認画面で選ぶ
- リザルト専用アイテムはリザルト画面にボタンとして出す
- 自動使用は原則やめ、選択済みのアイテムだけ消費する

### 3. アイテム定義に「使える場所」の情報がない

今の `ShopItemDefinition` は `id/name/iconLabel/description/price/accentColor` だけです。追加アイテムを増やすなら、使える場所や条件をデータで持たせた方が安全です。

追加したい項目例:

```ts
useContext: 'captureStart' | 'captureRun' | 'battleStart' | 'result' | 'stageLimit';
category: 'capture' | 'battle' | 'progress' | 'exchange' | 'cosmetic';
maxUsePerRun: number;
isAutoUseAllowed: boolean;
sortOrder: number;
```

これがあると、ショップ表示、ステージ選択時の候補表示、使用可否の判定を共通化できます。

## ステージ選択時に選べるようにする案

ステージカード上に全部のアイテムを並べると画面が狭くなるので、最初は `StageIntroScene` に「もちもの」枠を作るのがよさそうです。ステージ選択画面では「このステージで使えるアイテムあり」程度の小さな表示に留めると、画面が重くなりにくいです。

おすすめフロー:

1. ステージ選択でステージを選ぶ
2. ステージ導入画面に入る
3. 出るモンスターと問題内容の下に「もちもの」枠を表示
4. 使えるアイテムだけをボタン表示する
5. プレイヤーが ON/OFF を選ぶ
6. 「つかまえに出発！」で選択済みアイテムを消費して開始する

この方式なら、レアがいないステージで `レアベル` を表示しない、捕獲済みばかりのステージなら `ねらいレンズ` をおすすめしない、などの誘導もしやすいです。

## 追加したいアイテム案

### 捕獲サポート

- ねらいレンズ
  - 効果: そのステージの未捕獲モンスターが出やすくなる
  - 価格目安: 150から250コイン
  - 理由: 図鑑埋めのストレスを減らせます。レア確定より安く、普段使いしやすいです。

- かけら磁石
  - 効果: 次の捕獲で、もらえるかけら +1
  - 価格目安: 80から120コイン
  - 理由: 進化とアメ交換の両方につながるので、ショップと育成がつながります。

- じっくり時計
  - 効果: 次の捕獲で、スピードボーナスの判定を少しゆるくする
  - 価格目安: 60から100コイン
  - 理由: 学習アプリとして、苦手な子にも使いやすい補助になります。

- レアベル小
  - 効果: レア確定ではなく、レア出現率を大きく上げる
  - 価格目安: 200から350コイン
  - 理由: 1000コインのレアベルだけだと重いので、中間価格の商品があると買いやすいです。

### 対戦サポート

- まもりシール
  - 効果: 次の対戦で最初の被ダメージを1回軽減
  - 価格目安: 70から120コイン
  - 理由: げんきパンとは別軸の防御アイテムになります。

- はやときバッジ
  - 効果: 次の対戦で早く正解したときのダメージボーナスを上げる
  - 価格目安: 120から180コイン
  - 理由: 早く正確に解く動機づけになります。

- げんきパン大
  - 効果: 次の対戦で味方のHP +30
  - 価格目安: 160から220コイン
  - 理由: 現在のげんきパンの上位版として分かりやすいです。

### 進行・周回サポート

- おでかけチケット
  - 効果: ステージの残り回数が0でも1回だけ出発できる、またはそのステージの回数を1回回復する
  - 価格目安: 180から300コイン
  - 理由: もう少しだけ遊びたい時の救済になります。

- ふくしゅうノート
  - 効果: 直近で間違えた問題を次回出やすくする代わりに、クリア時の報酬を少し増やす
  - 価格目安: 50から90コイン
  - 理由: 学習効果と報酬がつながります。

- コインのおまもり
  - 効果: 次の対戦勝利時のコイン報酬 +20%
  - 価格目安: 100から160コイン
  - 理由: 対戦を回る意味が増え、ショップ経済も回りやすくなります。

### コスメ・長期目標

- ボールスキン
  - 効果: 捕獲ボールの見た目変更
  - 価格目安: 300から800コイン
  - 理由: 学習バランスを壊さず、余ったコインの使い道になります。

- ホーム背景
  - 効果: メインメニュー背景の変更
  - 価格目安: 500から1200コイン
  - 理由: 長く遊ぶプレイヤー向けのごほうびになります。

## 実装順のおすすめ

1. `なかまよび` の未実装を直して、型チェックを通す
2. `レアベル` と `ゲージボール` をステージ導入画面で選択式にする
3. `げんきパン` を対戦前の選択式にする
4. アイテム定義に `useContext` と `category` を追加する
5. ショップ画面をカテゴリ別、またはページ切り替え式にする
6. 新アイテムは `ねらいレンズ`、`かけら磁石`、`おでかけチケット` から追加する
7. 余ったコイン用にコスメ商品を追加する

## 仕様として決めたいこと

- アイテムは1回の出発で何個まで使えるか
- 捕獲サポートを複数同時に使えるか
- ステージ回数制限を回復するアイテムを許可するか
- レア確定アイテムを今後も残すか、確率アップ型へ寄せるか
- 低学年向けに、ヒント系アイテムを「ズル」ではなく「練習サポート」として扱うか

## 結論

今のショップは土台はできていますが、アイテムが自動で使われるため「買ったものを自分で使う楽しさ」が少し弱いです。まずは既存アイテムを選択式にして、`なかまよび` を完成させるのが効果的です。その後、図鑑埋め用の `ねらいレンズ`、育成用の `かけら磁石`、回数制限救済の `おでかけチケット` を足すと、ショップが学習・収集・周回の中心になりやすくなります。
