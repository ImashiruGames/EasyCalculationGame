ストーリー文章タグの使い方

このメモは、ストーリー作成画面のセリフと「せつめい」で使えるタグの一覧です。
JSONにはタグの文字列がそのまま保存され、ストーリー表示時に見た目へ変わります。

色を変える

[color:red]赤い文字[color]
[color:blue]青い文字[color]
[color:green]緑の文字[color]
[color:yellow]黄色の文字[color]
[color:#b52a24]好きな色[color]

色は [color:色名] で始めて、[color] で終わります。
使える色名は red, blue, green, yellow, black, white, ink, muted, water, panel です。
ひらがなでは、あか、あお、みどり、きいろ、くろ、しろ も使えます。

太字にする

[bold]ここだけ太字[bold]
[b]ここだけ太字[b]

下線を引く

[underline]ここだけ下線[underline]
[u]ここだけ下線[u]

ルビをふる

[ruby:きょう]今日[ruby]は いい天気です。
[ruby:こん,にち]今日[ruby]は いい日です。

ルビは [ruby:よみ]本文[ruby] で書きます。
コンマなしなら、本文全体の上に中央ぞろえでルビを置きます。
コンマありなら、本文を1文字ずつ分けて、それぞれの上にルビを置きます。
コンマは , と ， のどちらでも使えます。

動きをつける

[motion:bounce]ここだけはねる[motion]
[motion:sway]ここだけゆれる[motion]
[motion:twitch]ここだけビクッとする[motion]
[motion:slide]ここだけすべる[motion]
[move:bounce]ここだけはねる[move]
[move:sway]ここだけゆれる[move]

動きは [motion:動き名] で始めて、[motion] で終わります。
使える動き名は bounce, jump, sway, shake, twitch, jerk, slide, slip です。
日本語では、はねる、ぴょん、ゆれる、ゆら、ビク、びく、びくっと、すべる も使えます。
動きはずっと続くものではなく、短く二回ぶん動きます。

エフェクトをつける

[effect:glow]ここだけ光る[effect]
[effect:shrink]ここだけしぼむ[effect]
[effect:grow]ここだけふくらむ[effect]
[effect:silhouette]ここだけかげ[effect]

エフェクトは [effect:エフェクト名] で始めて、[effect] で終わります。
使えるエフェクト名は glow, light, shrink, small, vanish, grow, big, pop, silhouette, shadow です。
日本語では、ひかる、光、しぼむ、消える、ふくらむ、大きく、かげ、影 も使えます。

計算や図のタグ

[m]log[_:e]2[m]
[math](log[_:e]2)[^:2][math]
[math:frac(sqrt(5),2)]
[math:pow(log(e,2),2)]
[root:3]
[sqrt:5]
[log:2]
[^:2]
[_:e]
[clock:3,30]
[clock:6,30,7,30]
[frac:1,2]
[fraction:3,4]
[name:ピコリーフ]

[m] または [math] ではさむと、その中は数学用のフォントで出ます。
終わりも同じ [m] または [math] です。
[math:...] と書くと、frac や sqrt を組み合わせた数式を1つの部品として出します。
[math:frac(sqrt(5),2)] は、分子が√5、分母が2の分数になります。
[sqrt:2] はルート、[log:2] は底つきのlogです。
[^:2] は上付き、[_:e] は下付きです。

時計は [clock:時,分] で止まった時計を出します。
[clock:はじめの時,はじめの分,おわりの時,おわりの分] と書くと、はじめからおわりへ針が動きます。

文章例

[name:ピコリーフ] は [color:green]くさ[color] の なかまです。
[bold][root:3][bold] は だいたい 1.732 です。
[m](log[_:e]2)[^:2][m] のように書けます。
[math:frac(sqrt(5),2)] のように、分数の中にルートを入れられます。
[math:pow(log(e,2),2)] のように、logと上付きも組み合わせられます。
[log:2]8 は 3 です。
[clock:3,30] の はりを 見てみよう。
[clock:6,30,7,30] で 1時間 すすみます。
[frac:1,2] と [frac:1,3] を くらべよう。
[ruby:きょう]今日[ruby]の ポイントです。
[ruby:こん,にち]今日[ruby]は [color:red]大切[color] です。
[underline]ここがたいせつ[underline] です。
[motion:sway]ゆらゆら[motion] うごきます。
[motion:twitch]ビクッ[motion] とします。
[motion:slide]すっとすべる[motion] うごきです。
[effect:shrink]すうっと小さく[effect] なります。
[effect:grow]小さいところからふくらむ[effect] ように出ます。

タグを重ねる例

[color:red][bold]とてもたいせつ[bold][color]
[color:blue][underline]ここを見る[underline][color]
[color:green][motion:bounce]ピョン！[motion][color]
[effect:glow][bold]ここがポイント[bold][effect]

気をつけること

タグを始めたら、同じタグで終わります。
[color:red] の終わりは [color] です。
[bold] の終わりは [bold] です。
[underline] の終わりは [underline] です。
[motion:sway] の終わりは [motion] です。
[effect:glow] の終わりは [effect] です。

名前タグは、ストーリー作成で選べる人やモンスターの名前、IDを探します。
見つからない名前は、タグの文字のまま表示されます。
