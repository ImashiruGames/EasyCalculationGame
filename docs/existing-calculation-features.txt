読み方
- 「ジャンル」は stageCategoryId のまとまりです。
- 「小ジャンル」はステージ名、サブタイトル、themeLabel、problemRule から読める実際の練習内容です。
- ルールが複数行あるステージは、問題ごとにどれかのルール行がランダムに選ばれます。
- blankSlot がない整数・分数・小数などは、基本的に計算結果を □ にして答えます。
- blankSlot が left/right のときは、左の数または右の数を □ にして答えます。
- blankSlot が rightDenominator などの分母欄のときは、分数の分母を □ にして答えます。
- 数字入力は共通のテンキーです。小数問題と √ の小数値問題だけ小数点キーを使えます。
- 二枠回答は、1つ目を入力して「きめる」を押すと2つ目の欄へ進み、2つそろってから判定されます。
- 学年レベルは practiceLevels.ts の order に対応します。2=2年生、3=3年生、4=4年生、5=5年生、6=6年生、7=中学1年生/中学、8=中学2年生、9=中学3年生です。10は通常の学年ラベルに対応がなく、「ぜんぶ」表示で見る前提のデータです。

回答方式の種類
- 一枠数字: □ に入る整数をテンキーで1つ入力します。
- 一枠小数: □ に入る小数をテンキーと小数点で入力します。
- 時計の時または分: アナログ時計を見て、時または分を一枠数字で入力します。時は0/12/24時を12時間表記として扱います。
- 時計の時分二枠: 「□時間□分」の2つの数字を入力します。
- 商とあまり二枠: 「□ あまり □」の2つの数字を入力します。
- √二枠: √の答えを「係数」と「根号内数」など2つの数字で入力します。係数1は空入力でも許される形式があります。
- 分数一枠: 分数表示の分子または分母の □ に入る数字を1つ入力します。
- 虫食い数字: 2けたの式のどこか1けただけが □ になり、その数字を1つ入力します。

- ルール: 表示係数1-5、表示上の根号内数2-50。整理後に同じ根号内数になり、結果が正になるものだけ。
- 回答方式: √二枠。係数と根号内数を入力します。

デバッグCSV上のステージ

前提
- debug_stages.csv と debug_stage_problem_rules.csv は、開発中かつURLに debug=1 があるときだけ通常CSVへ読み足されます。
- 現在のカテゴリ一覧関数は debug カテゴリを通常一覧から除外しているため、一般プレイ用の本編ステージではありません。

ジャンル: デバッグ (debug)

D1. debugAdd / おためしたしざん
- 小ジャンル: 1-3をたす。
- ルール: 1-3 + 1-3 = □。答え2-6。一枠数字。

D2. debugMinus / おためしひきざん
- 小ジャンル: 5-9から1-4をひく。
- ルール: 5-9 - 1-4 = □。答え1-8。一枠数字。

D3. debugLong / つかまらんチェック
- 小ジャンル: 1をたす問題を多めに解かせる確認用。
- ルール: 1 + 1-9 = □。答え2-10。一枠数字。

D4. debugCarry / くりあがりチェック
- 小ジャンル: 一桁同士のくり上がり足し算。
- ルール: 4-9 + 4-9 = □。答え10-18、digitRule=carryRequired。一枠数字。

D5. debugBorrow / くりさがりチェック
- 小ジャンル: くり下がり引き算。
- ルール: 10-18 - 1-9 = □。答え1-9、digitRule=borrowRequired。一枠数字。

D6. debugBlank / あなうめチェック
- 小ジャンル: 足し算と引き算の穴埋め。
- ルール1: □ + 1-9 = 10-18。答えは左の数。一枠数字。
- ルール2: 1-9 + □ = 10-18。答えは右の数。一枠数字。
- ルール3: 10-18 - 1-9 = □。答えは差。一枠数字。

D7. debugTimes / かけ算チェック
- 小ジャンル: 九九のまとめ確認。
- ルール: 2-9 × 2-9 = □。答え4-81。一枠数字。

D8. debugDivide / わり算チェック
- 小ジャンル: あまりなし・あまりありの両方。
- ルール1: 2-81 ÷ 2-9 = □。商1-9、あまり0。一枠数字。
- ルール2: 2-81 ÷ 2-9 = □ あまり □。商1-9、あまり1-8。商とあまり二枠。

D9. debugFraction / ぶんすうチェック
- 小ジャンル: 分数のたしひき・通分・等しい分数。
- ルール1: 同分母分数の足し算。答えの分子を一枠数字。
- ルール2: 異分母分数の引き算。答えの分子を一枠数字。
- ルール3: 等しい分数で右分母を答える。一枠数字。

D10. debugFractionMul / ぶんすうかけわり
- 小ジャンル: 分数のかけ算・わり算。
- ルール1: 分数 × 分数。答えの分子を一枠数字。
- ルール2: 分数 ÷ 分数。答えの分子を一枠数字。

D11. debugDecimal / しょうすうチェック
- 小ジャンル: 小数のくり上がりあり/なしと2けた小数ひき算。
- ルール1: 小数1けた足し算、digitRule=noCarry。一枠小数。
- ルール2: 小数1けた足し算、digitRule=carryRequired。一枠小数。
- ルール3: 小数2けた引き算。一枠小数。

D12. debugClock / とけいチェック
- 小ジャンル: 時計の時刻と分の変換。
- ルール1: 何時か答える。一枠数字。
- ルール2: 5分きざみで分を答える。一枠数字。
- ルール3: 60-110分を□時間□分へ直す。時計の時分二枠。

D13. debugRoot / ルートチェック
- 小ジャンル: √の正負、整理、同じ√のたし算。
- ルール1: 平方根を正負2つで答える。√二枠。
- ルール2: √nをa√bに整理する。√二枠。
- ルール3: 同じ根号内数の√項をたす。√二枠。

D14. debugShapeArea / 図形ひろさ
- 小ジャンル: 長方形の面積、または辺の穴埋め。
- ルール1: たて2-12、よこ2-12、ひろさ4-144。答えは面積。一枠数字。
- ルール2: たて□、よこ2-12、ひろさ4-144。答えはたて。一枠数字。
- 表示方式: 図形問題として、たて・よこ・ひろさを表示します。

D15. debugVertical / ひっ算チェック
- 小ジャンル: 縦書きの足し算・引き算・かけ算。
- ルール1: 10-99 + 10-99 = □。くり上がり必須。一枠数字。
- ルール2: 20-99 - 10-89 = □。くり下がり必須。一枠数字。
- ルール3: 10-99 × 2-9 = □。一枠数字。
- 表示方式: ひっ算として縦に表示します。

D16. debugMissingDigit / 虫食い算
- 小ジャンル: 2けた式の1けた虫食い。
- ルール1: 10-49 + 10-49 = 20-98。くり上がり必須。虫食い数字を一枠入力。
- ルール2: 10-49 + 10-49 = 20-98。くり上がりなし。虫食い数字を一枠入力。
- ルール3: 20-99 - 10-89 = 10-89。くり下がり必須。虫食い数字を一枠入力。
- ルール4: 20-99 - 10-89 = 10-89。くり下がりなし。虫食い数字を一枠入力。
- 補足: 隠れる場所は左の十の位/一の位、右の十の位/一の位、答えの十の位/一の位のどれかです。

ボス戦
- 通常のステージ一覧から入るボスは、そのページに表示されているステージIDを sourceStageIds として受け取り、各ステージの problemRule を混ぜて出題します。
- boss-addition-page1: additionカテゴリ1ページ目用。通常導線では、そのページの足し算ステージ3種類を混ぜます。
- boss-addition-page2: additionカテゴリ2ページ目用。通常導線では、そのページの足し算ステージ3種類を混ぜます。
- boss-addition-page3: additionカテゴリ3ページ目用。通常導線では、そのページの足し算ステージ2種類を混ぜます。
- boss-subtraction: subtractionカテゴリ共通。通常導線では、そのページの引き算ステージを混ぜます。
- boss-multiplication: multiplicationカテゴリ共通。通常導線では、そのページのかけ算ステージを混ぜます。
- debug-boss-page: debugAdd と debugMinus を混ぜます。
- debug-boss-mix: debugCarry、debugBorrow、debugTimes、debugDivide、debugDecimal を混ぜます。
- debug-boss-hard: debugFraction、debugFractionMul、debugClock、debugRoot、debugLong を混ぜます。
- debug-boss-stats: debugCarry、debugBorrow、debugBlank、debugTimes、debugDivide を混ぜます。
- debug-boss-new-problems: debugShapeArea、debugVertical、debugMissingDigit、debugCarry、debugBorrow を混ぜます。
- debug-boss-weakness: debugShapeArea、debugVertical、debugMissingDigit、debugCarry、debugBorrow を混ぜます。

実装上存在する問題種別の総覧
- integer: 整数の +, -, ×, ÷。CSV上は主に +, -, × を使用。結果、左、右を空欄にできます。
- integerDivision: 整数のわり算。あまりなし一枠、あまりあり二枠に対応。
- decimal: 小数の +, -。小数点入力に対応。0-3けたまでの小数けた指定に対応。
- clockTime: アナログ時計の時刻読み。時、分、または時刻結果を答えられます。
- clockMinuteConversion: 分を時間と分へ直す問題。一枠で分だけ、または二枠で時間と分を答えます。
- sameDenominatorFraction: 同分母分数の +, -。主に答えの分子を入力します。
- equivalentFraction: 等しい分数。分子または分母の穴埋めに対応。
- differentDenominatorFraction: 異分母分数の +, -。通分後の答えの分子を入力します。
- fractionProductQuotient: 分数の ×, ÷。答えの分子を入力します。
- squareRoot: 平方根、√の整理、√分数、√近似値、√大小比較、√式の加減に対応。
- shapeArea: 図形の面積、または辺の穴埋め。現状はデバッグステージのみ。
- verticalArithmetic: 縦書き表示の四則。現状はデバッグステージのみ。
- missingDigitArithmetic: 2けた式の虫食い算。現状はデバッグステージのみ。
