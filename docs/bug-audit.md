# バグ・挙動リスク記録

作成日: 2026-05-20

## 修正済み

### 穴埋め計算の入力欄が式の穴と一致しない

10を作る問題は `2 + □ = 10` のように答え欄が右端ではないが、以前は入力欄が常に式の右端に固定されていた。

対応:
- 問題データに `answerSlot` を追加
- `left` / `right` / `result` のどこが穴かを持てるようにした
- 捕獲ゲーム画面では、穴の位置に入力ボックスを描画するようにした

### シーン初期化データがないと落ちる可能性

`scene.start()` がデータなしで呼ばれた場合、`init(data)` 内で `data.stageId` などを読むとクラッシュする可能性があった。

対応:
- `StageSelectScene`
- `StageIntroScene`
- `CaptureGameScene`
- `ResultScene`

上記の `init(data)` を `data?` として扱い、デフォルト値へ戻すようにした。

### 保存に失敗した環境でクラッシュする可能性

プライベートブラウズ、容量制限、ブラウザ設定などで `localStorage.setItem` が失敗すると、捕獲処理中にゲームが止まる可能性があった。

対応:
- 保存処理を `try/catch` で保護
- 保存できない場合でも捕獲演出と画面遷移は止めない
- 捕獲直後のリザルトには、保存結果ではなくその場で計算した捕獲数も渡すようにした

### 古い保存データのモンスターIDが捕獲種類数に混ざる

モンスター追加・削除後に古い保存データが残ると、存在しないIDがユニーク捕獲数に入る可能性があった。

対応:
- 保存データ読み込み時に、現在のモンスターカタログに存在するIDだけを採用するようにした

### ステージ解放条件が抜けていた

以前の仕様にあった「こおりのどうくつは2種類捕獲で解放」「ほのおのやまはComing Soon」が、モンスター追加後のステージデータから抜けていた。

対応:
- こおりのどうくつ: 2種類で解放
- ほのおのやま: Coming Soon
- 以降のステージにも仮のユニーク捕獲数条件を設定

### ステージ詳細から戻るとページ位置が失われる

後半ページのステージ詳細から戻ると、ステージ選択の1ページ目へ戻ってしまう可能性があった。

対応:
- 戻る時に `stageId` を渡し、該当ステージがあるページへ戻すようにした

### 高速スワイプで捕獲ボールが反応しにくい可能性

スワイプが速すぎると `pointermove` が十分に発火せず、上方向に投げた判定にならない可能性があった。

対応:
- `pointerup` 時点の座標でも最終移動量を計算
- キャンバス外で指を離した場合に備えて `pointerupoutside` も見るようにした

### 先頭ゼロ入力を正解扱いする

`01` が `1` として正解になり、数字入力の練習としてよくない挙動になる可能性があった。

対応:
- 入力が `0` の状態で次の数字を押したら、先頭ゼロを残さず置き換えるようにした

### 効果音がブラウザ側で停止したままになる可能性

モバイルブラウザでは AudioContext が `suspended` のままになることがある。

対応:
- 効果音を鳴らす前に `resume()` を試すようにした
- 失敗してもゲームは止めない

### 進化ボタンが押せそうに見える

進化機能はまだ本実装されていないのに、リザルトで `しんか！` と表示されると、押せる機能のように見える。

対応:
- `しんか準備中` という表示に変更
- まだ無効ボタンとして扱う

## 未修正・要相談

### 進化そのものは未実装

進化条件の計算と表示はあるが、捕獲数を消費して次の進化先へ進める機能はまだない。

対応候補:
- 進化ボタンを有効化する
- 保存データに進化済み状態を追加する
- 図鑑表示と捕獲対象に進化後をどう出すか決める

### 図鑑・ショップ・トレーナー戦は実装済み

現状は最初の実装版として、図鑑・ショップ・モンスターしょうぶまで触れる状態。

対応候補:
- 図鑑は検索や並び替えが必要になったら追加する
- ショップはアイテム数が増えたらページ分けする
- 対戦は報酬や難易度調整を追加する

### ステージ詳細で未捕獲モンスターの姿が見える

ステージ選択では未捕獲をシルエットにしているが、ステージ詳細では候補モンスターを通常表示している。

対応候補:
- 未捕獲はシルエット表示に統一する
- 最初のステージだけ通常表示にする
- レアだけシルエットにする

### レア出現に天井がない

レアは低確率にしているが、運が悪いと長く出ない可能性がある。

対応候補:
- 一定回数レアなしなら次回レア率を上げる
- アイテムで確定出現させる

## 追加修正済み

### 同じ計算問題が連続することがある

問題はランダム生成なので、同じ式が続く可能性がある。

対応:
- 捕獲モードと対戦モードで、直前と同じ式は数回だけ引き直すようにした
- 問題候補が少ないステージでも止まらないよう、引き直し回数には上限を設けた

### 新規捕獲時のNEW表示が捕獲数表示に重なる

新しく捕まえた時だけ出る `NEW` 表示が、捕獲数とかけら数の行に近く、数字が伸びた時に重なる可能性があった。

対応:
- `NEW` をリザルトカード右上のバッジに変更
- 捕獲数とかけら数の行は中央揃えに戻し、NEW表示と分離した

### ボタン押下アニメーションが重なって残る可能性

連打や押したまま外へ出る操作で、同じボタンに対する拡大縮小Tweenが重なり、見た目が少し遅れて戻る可能性があった。

対応:
- ボタンの押下状態を保持し、押していない状態の `pointerup` ではクリック処理を走らせないようにした
- 新しい押下/復帰Tweenを始める前に、同じボタンの既存Tweenを止めるようにした

## 未修正・要相談

### 自動テストがない

現状は型チェックとビルド確認が中心で、問題生成や保存正規化の自動テストはない。

対応候補:
- 問題生成の範囲テスト
- ステージ解放条件のテスト
- 保存データ正規化のテスト
