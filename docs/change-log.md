# 変更記録

このドキュメントは、実装した修正や追加した機能を後から追えるように記録する場所です。

## 2026-05-25

### 図鑑・タイトルかざり

- 図鑑に「みつけた子だけ」表示を追加。捕獲済みモンスターだけに絞り込み、ページ数も絞り込み後の件数で表示するように変更。
- ホームと図鑑から「タイトルへんしゅう」へ進めるように追加。
- タイトル画面に表示する5枠のモンスターを、見つけたモンスターから選んで保存できる「タイトルかざり」画面を追加。
- タイトル画面は保存済みのタイトルかざりを優先し、未設定なら従来の5体を表示するように変更。
- タイトルかざり画面を、左にモンスター置き場、中央に実タイトル比率のプレビュー、右に道具列を置く編集用レイアウトへ変更。
- タイトルかざり画面の主要な位置・サイズ・文字サイズを `layoutConfig.ts` に集約し、デモ中に細かく調整しやすいように整理。
- タイトルかざりの道具に、削除、小さくする、大きくする、回転、キャラクター変更を追加。回転角度も保存してタイトル画面に反映するように変更。
- タイトルかざりのプレビューでは編集中のモンスターだけをドラッグできるようにし、重なった下のモンスターへ触れてしまわないように変更。左の「おく子」は「モンスター」に変更し、カード内の「おく」「配置中」表示を削除。
- タイトルかざり画面の左ページ送りをモンスター欄内に収め、下の確認パネルには配置済みモンスターを横並びで表示。カードをタップして編集対象を切り替えられるようにし、`layoutConfig.ts` のタイトルかざり設定には調整用コメントを追加。
- タイトルかざり画面の道具に「背景」ボタンを追加し、購入済みのタイトル背景を編集画面から順送りで切り替えられるように変更。
- ショップの購入完了メッセージを「○○を買ったよ！」に統一し、アイテム購入と背景購入で購入音が鳴るように整理。
- ステージ別に捕獲したモンスターを保存し、ステージ「ぜんぶ」トロフィーが別ステージの同一出現構成だけで解除されないように変更。

## 2026-05-24

### 軽量化・整理

- 捕獲モードのステージ別BGMで、90msごとのスケジューラ内で移調済みノート配列を作り直していたため、再生開始時にパターンを決めてキャッシュするように変更。
- モンスター出現抽選を、重み付きID配列の都度生成から累積重み抽選へ変更。レア出現率の小数重みもそのまま扱えるようにした。
- ステージ一覧のカテゴリ絞り込みを毎回 `filter` する形から、起動時に作るカテゴリ別Map参照へ変更。
- 対戦パーティ選択の図鑑順比較で、毎回Mapを作り直さないように共通の図鑑順インデックスを追加。
- トレーナー難易度順、トロフィー解放数、図鑑登録数、ステージカテゴリ集計など、小さい配列生成を伴う処理をループ・キャッシュ中心に整理。
- `docs` 配下に残っていた画像加工の中間フォルダとQA確認用スクショを削除。ゲームで使う `public/assets`、ビルド生成物の `dist`、依存パッケージの `node_modules` は対象外として保持。
- ショップのかけら→アメ交換候補が3件で切れていたため、3件ずつのページ送りに変更。候補が増えても画面からあふれないよう、アメ→コイン欄の位置も調整。
- 図鑑で未発見の進化先を開いたとき、進化元名や捕獲導線を出さず「まだみつけていないモンスターがしんかしたすがただよ」と表示するように変更。

## 2026-05-22

### 進化導線

- 2回進化するモンスターが最終進化に進みやすいよう、かけらを個別形態ではなく進化系列で共有する扱いに変更。
- 結果画面で同じ進化系列の所持済み形態を確認し、フタリーフなど中間進化が進化可能なら、捕まえた直後のモンスターがピコリーフでも中間進化の進化ボタンを出すように変更。
- ショップの「かけら→アメ」候補は、同じ進化系列が重複表示されないように、所持済みの一番進んだ形態を代表表示するように変更。

### 追加・変更

- 対戦モードを、こちらの攻撃後に相手が反撃する形式から、相手も計算ゲージをためて自動で攻撃するリアルタイム形式へ変更。
- 対戦画面の相手パネルに「あいても けいさん中」ゲージを追加。
- 勝敗決定、モンスター交代、画面遷移時に相手の計算ゲージが残って攻撃し続けないように停止処理を追加。
- 対戦モード設計メモを、リアルタイムバトルの考え方に合わせて更新。
- 対戦中の相手ゲージ文言と「あいても せいかい！」表示を削除し、ゲージ・ダメージ数字・HP変化で伝えるように変更。
- 対戦画面ではトレーナーの常設アイコンと名前表示を出さず、計算とモンスターの動きに視線を寄せるように変更。
- 相手トレーナーが複数のモンスターを出せるようにし、1体ひとやすみになると次の相手モンスターへ自動交代するように変更。
- こちらの手持ちアイコンをタップすると、対戦中に前へ出すモンスターを交代できるように追加。
- 勝利画面で、最後に負けた相手モンスターを目が×・絆創膏つきの「まいった」表情で表示するように追加。
- 対戦相手選択画面で、相手の手持ち数と最初に出るモンスターを見られるように変更。
- 対戦トレーナーをステージ順に9人へ増やし、計算ルールもステージテーマに合わせて段階的に難しくなるように変更。
- 勝利報酬としてコインと属性アメを追加。高レベルの対戦相手ほど報酬量が増えるように設定。
- 保存データに対戦勝利数を追加し、勝利画面と相手選択画面で勝利数や報酬を確認できるように変更。
- 対戦相手が増えたため、相手選択画面にページ送りを追加。
- 対戦相手選択画面に「れんぞくたいせん」を追加。手持ちを一度選ぶと、レベルの低い順に相手が続けて出るように変更。
- 連続対戦では、勝利後に「つぎのあいてへ」でそのまま次戦へ進み、手持ちの残りげんきを引き継ぐように追加。
- 連続対戦で3人ごとに宝箱ボーナスが出るように追加。宝箱では追加コイン、属性アメ、全員のげんき小回復を得られる。
- 連続対戦で負けたとき、獲得済みの報酬はそのまま残ることが伝わる文言を追加。

## 2026-05-21

- 進化条件を「捕獲数」ではなく「キャラクターのかけら」に変更。

- 進化ボタンを押して進化が成功したとき、進化元モンスターのかけらを必要数だけ消費するように変更。
- 属性アメとコインを保存データに追加。
- ショップ画面で「かけら5こ → 属性アメ1こ」「属性アメ1こ → 30コイン」の交換をできるように追加。
- リザルト画面で、進化素材として「かけら」と「属性アメ」の所持数を見られるように変更。
- かけらが足りない場合でも、対応する属性アメが足りていればアメで進化できる導線を追加。
- 図鑑画面に、捕獲数だけでなくかけら・属性アメ・コインの表示を追加。

### 追加修正

- 図鑑カード内の「属性 / かけら」表示が詰まらないように、文字サイズと折り返し幅を調整。
- 図鑑詳細パネル下部の「わざ」「かけら」「くわしくみる」の行が重ならないように配置を調整。
- ショップ画面の「かけら5こ → アメ1こ」見出しと交換カードが重ならないように縦位置を調整。
- ショップの交換カード内で、説明テキストが交換ボタンに入り込まないように2行表示へ変更。
- 捕獲画面の開始時に「モンスターがあらわれた！」から「3,2,1,GO!」へ進む開始演出を追加。
- 問題に1秒未満で正解したとき、捕獲ゲージの増加量が1.5倍になるスピード倍率を追加。
- スピード倍率を「1秒未満: 1.5倍」「3秒未満: 1.3倍」「5秒未満: 1.1倍」の3段階に変更。
- 仮対戦モードとして、相手選択、手持ち3匹までの選択、計算正解でわざを出すバトル画面を追加。
- 対戦モードの楽しさを整理した `docs/battle-design.md` を追加。
- 対戦モードを、トレーナー本人ではなく相棒モンスター同士の勝負に見えるように整理。
- 対戦のおすすめタイプ、タイプ一致ボーナス、コンボ倍率、チームゲージを削除し、小1向けに判断軸を減らした。
- 対戦画面の文言を `HP` / `ダメージ` から `げんき` / `わざ` へ寄せ、正解テンポを楽しむ設計に変更。
- 間違えたときは負けにせず、連続正解が止まるだけにして低ストレス設計を維持。
- モンスターに対戦用HPを追加し、進化段階・レア度・形・攻撃力から個性が出るように自動計算。
- 対戦を1問ごと交代ではなく、前に出た1匹がげんき0になるまで戦う形に変更。
- 相手の相棒モンスターもわざを返すようにして、相棒モンスター同士の勝負感を追加。
- 属性相性を `とくい` / `にがて` の軽い倍率として追加。
- ダメージは長い文章ではなく、対象モンスター近くのランダム位置に数字で表示するように変更。
- ショップに購入タブを追加し、`ゲージボール`、`レアベル`、`げんきパン` を購入できるように変更。
- `ゲージボール` は次の捕獲で最初の正解時に消費され、その捕獲中のゲージ増加を強化するように追加。
- `レアベル` はレアモンスターがいるステージで次の出発時に消費され、レアモンスターが確実に出るように追加。
- `げんきパン` は次の対戦開始時に消費され、手持ちモンスター全員のげんきを+15するように追加。
- 保存データにショップアイテムの所持数を追加。
