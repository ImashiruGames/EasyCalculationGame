first-read

このプロジェクトは、小学生向けの一けた計算練習アプリです。
まず全体を見るときは、このファイルを読んでから、各フォルダの「このフォルダについて.txt」を見てください。

主なフォルダ

- 計算以外の画めんチェックは docs/screen-layout-preview.html です。
  画めんごとに気になる文字を見るメモは docs/non-calculation-layout-audit.md です。

- src
  アプリのTypeScriptコードです。画面、出題、セーブ、進行などはここにあります。
  

- public
  Viteがそのまま配信する静的ファイルです。画像素材は public/assets にあります。

- public/assets/battle-reward
  ボスしょうぶに勝った時の、ごほうび箱演出で使う透過PNG画像を置く場所です。

- docs
  仕様メモ、調査メモ、制作メモ、画像確認用ファイルを置く場所です。

- tests
  npm test で動かすテストがあります。

- vite
  開発用と本番用のVite設定があります。

- tmp
  動作確認のスクリーンショット、ログ、一時データを置く場所です。
  ルート直下や tmp 直下に散らばっていたログは、入れられるものを tmp/logs に移しました。
  容量が大きかった tmp/chrome-* の一時プロファイルは削除済みです。
  tmp/transfer-dev.err.log と tmp/transfer-dev.out.log は別プロセスで使用中だったため、今回は移動していません。

- dist
  npm run build で作られる配布用ファイルです。生成物なので、基本的に手で直しません。

- node_modules
  npm install で入る外部ライブラリです。外部依存なので、この中には説明ファイルを追加していません。

- .git
  Gitの管理データです。ふつうは直接さわりません。

ルート直下の主なファイル

- package.json
  起動、ビルド、テストのコマンドと依存ライブラリの情報です。

- package-lock.json
  npm依存の固定情報です。

- index.html
  アプリを表示するHTMLです。

- tsconfig.json
  TypeScriptの設定です。

- README.md
  元になったPhaserテンプレートの説明が中心です。

- log.js
  package.json の dev/build コマンドで使われるテンプレート由来の通信スクリプトです。

整理の方針

- コード構造の整理内容と確認結果は docs/refactoring-report.md にあります。
  出題は src/game/problem、問題表示は src/game/ui/problem、保存処理は src/state/save に分かれています。

- ログや一時確認ファイルは tmp 側に寄せる方針でお願いします。
tmpに作成した一時ファイルは、基本的に確認が終わった後、「前に使用した一時ファイルは削除する」ことを徹底してください。
- src/data/stories
  エクスポートしたストーリーJSONを置く場所です。index.ts からJSON内の story.id で探して、ゲーム内の関数から呼び出せるようにします。
- src/data/stageProblems
  ステージごとの手作り方眼問題JSONを置く場所です。stageId と problemNo から問題を探せるようにします。
- src/data/stageProblems/g2-kakezan-kangae
  かけ算の考えステージでつかう、手作りほうがんもんだいJSONがあります。
- 新しい機能や新しい出題ジャンルを実装したら、src/data/titleNotices.ts の先頭にお知らせを追加してください。
  id は新しい値にすると、タイトル画面の NEW 表示に反映されます。
- お知らせ一覧など、下へ増えるUIを作る時は、4件ずつのページ送りやスクロールを用意し、画面下で見切れないようにしてください。
- 長さの7ステージは src/data/csv/stages.csv の g2-nagasa- で始まる行です。
  出題は src/game/problem/measurementProblems.ts、表示は CaptureProblemView.ts にあります。
- 新しいステージや既存ステージへの問題追加を知らせるときは、stages.csv の newContentVersion に新しい日付や版名を入れてください。
  ジャンルとステージに new! が出て、ステージを開くとその端末では消えます。再度知らせるときは値を変えてください。
  既読管理は src/state/stageNotices.ts です。CSVはUTF-8 BOM付きで保存してください。
